# Product decisions

## 2026-08-24 — V1 information architecture

**Decision:** The live app shell exposes the connected Career OS core (Dashboard, Profile, Resume, Goals, Jobs, Roadmaps, Interview, Copilot). Academic and workspace modules stay in V1 scope but are persona tools, not equal primary nav.

**Why:** Dumping every historical page into the sidebar recreated isolated tools and mixed experimental UI with the career loop. The user's V1 definition is *one connected system*, not maximum tabs.

**Not deferred out of V1:** Research, Experiment Studio, Graduate Hub, Admissions, Notes, Workspaces, Skill Forge, Admin. They must be restored through the same profile/skills/memory data, gated by persona, without new routers or duplicate systems.

## 2026-08-24 — Brand

**Decision:** User-facing name is Saarthi. Saarthilink was a visual experiment and is retired from the product UI.
